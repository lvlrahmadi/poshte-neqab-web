# پشت نقاب

نسخه وب نصب‌پذیر برنامه «پشت نقاب».

برای انتشار با GitHub Pages، این فایل‌ها را در ریشه مخزن عمومی قرار دهید و در Settings → Pages گزینه Deploy from a branch و شاخه main / ریشه (root) را انتخاب کنید.

اطلاعات بازی در حافظه محلی همان مرورگر ذخیره می‌شود و در سرور بارگذاری یا بین دستگاه‌ها همگام‌سازی نمی‌شود.
